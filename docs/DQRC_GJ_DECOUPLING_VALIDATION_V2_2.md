## Answers to the 10 required questions

1. **What is the physical causal latency?** `ell_causal = 0` for EVERY feature group tested (X_M, X_P, X_M+X_P, X_P_perp, cross) — proven by direct intervention: a single-timestep input perturbation is visible in the features at the SAME timestep it occurs, with a tolerance (1e-6) set 100x above a measured repeated-identical-run noise floor (~1e-8, i.e. floating-point round-off in this project's exact `shots=1` density-matrix simulation).
2. **Was V2.1's `ell_0` actually peak-memory delay?** Yes, confirmed directly: at the same reference point, `ell_peak = 7` (V2.1's `ell_0`, using the same argmax-of-C_{1,tau} definition) while `ell_causal = 0` — they disagree by the full width of the tested delay range. V2.1's "causal latency" was never a causal-latency measurement.
3. **Does the architecture retain present-input (tau=0) nonlinearity?** Inconsistently and fragilely. At the fixed V1-continuity reference point, `NL_0_signed = 0.202` (real, nontrivial). Across the four actual V2.1 candidates (8 screening evaluations: 4 candidates x 2 exploratory seeds), **7/8 evaluations showed `NL_0_signed ~ 0` (rejected as non-trivial)**; the one exception (candidate `m=0.212,g=0.405,J=0.205`, seed -201) showed `NL_0_signed=0.591`, but a SECOND independent seed at the exact same candidate (part of the Phase 9 stencil) showed `NL_0_signed=-0.001` — the signal did not reproduce.
4. **How much standalone nonlinear capacity survives?** At the reference point, `eta_NL(0) = 0.229` (23% retained, NOT flagged by the 0.1 suppression diagnostic). At delay 5, the ratio computation became numerically degenerate (`eta_NL(5)` computed to an absurd ~3.75e7 because the standalone denominator crossed near zero) -- flagged here as a known limitation of a raw ratio between two signed quantities, not a real retention estimate at that delay.
5. **Does the processor carry independent temporal memory?** Consistent with every prior pass: yes. The matched-standalone/DQRC feature-budget scan (Phase 7) shows `X_P` alone reaching `M_signed=6.55` at budget 32 (vs `X_M`'s own budget-3 value of `1.54`), and `X_P_perp` (residualized against `X_M`, train-fit only) still reaches `5.14` at budget 32 -- most of the processor's memory-like capacity is independent of the memory register.
6. **Does finite reset improve separation at identical (fixed) delays?** No evidence found. At the top screened candidate, `NL_0_signed` INCREASES monotonically with more persistence: `K=1: -0.003`, `K=4: 0.174`, `K=None: 0.731`. Reducing persistence did not help isolate present-input nonlinear processing; if anything, persistence helped both `M` and `NL_0`.
7. **Does any candidate have stable, approximately orthogonal control responses?** No. Derivative-stability analysis (Phase 10, 4 methods x 2 exploratory seeds) found only **1 of 6 decisive derivatives STABLE** (`dM/dm~`; every `dNL_0/d*~` derivative and `dM/dg~`, `dM/dJ~` were UNSTABLE). Per the explicit V2.2 rule, Gates C/D/E were therefore correctly reported as **NOT EVALUABLE**, not FAIL — an unstable derivative cannot support a decisive ratio claim either way.
8. **Was held-out confirmation justified and executed?** Not justified, and NOT executed. The preregistered Phase 15 advancement checklist (7 criteria) was applied to the top-ranked screening candidate: 5/7 passed, but criterion 3 (derivatives sufficiently stable) failed, which also forced criteria 4/5 to fail by the checklist's own construction. Per Rule 5/6, CONFIRM was correctly skipped.
9. **What is the highest supported claim level?** **Level 2** (memory back-action reduced) -- now further corroborated by the 4-way back-action decomposition (Phase 13): disabling memory-export (theta=0) reduces disturbance to EXACTLY 0.0000, while disabling processor-reception (phi=0) barely changes it (0.0433 vs the full interface's 0.0433) -- ALL measurable back-action traces to the theta (memory-ancilla) coupling, none to phi alone, a clean, physically sensible, reproducible decomposition. Level 3 (fixed-delay control decoupling) is explicitly NOT supported: 7/8 screening evaluations found no nontrivial tau=0 signal at all, and the one exception's derivatives were overwhelmingly unstable.
10. **What architecture change is recommended if V2.2 fails?** Per Outcome F (see Decision below): stop the current architecture's confirmation campaign and pursue the Krylov-sectorized memory redesign that V1/V2/V2.1 have all pointed toward -- not implemented in V2.2, consistent with Rule 3.

## Claim ladder

- Level 1 (directional information transfer): **supported**.
- Level 2 (reduced memory back-action): **supported**, now with a 4-way physical decomposition isolating the theta coupling as the sole source.
- Level 3 (local fixed-delay control decoupling): **NOT supported** -- Gate B failed (5/6 unstable derivatives), so Gates C/D/E are NOT EVALUABLE, and separately, 7/8 raw screening evaluations found no nontrivial NL_0 at all.
- Level 4 (seed/neighborhood-robust decoupling): **not evaluated** (no candidate advanced to CONFIRM).
- Level 5 (matched-resource Pareto expansion): **not evaluated**.

**Highest level actually supported: Level 2.**

## Decision: **Outcome F -- No candidate approaches the selectivity gates**

Literally 0/4 V2.1 candidates demonstrated a combination of nontrivial-tau=0-capacity + stable derivatives + low back-action + non-degenerate response geometry across even 2 exploratory seeds. Only 1/8 screening evaluations cleared the basic nontriviality bar, and that single survivor's own follow-up measurement (a different seed at the identical candidate) immediately produced a near-zero result, and its derivatives were 5/6 unstable. This is not evidence that the memory-nonlinearity tradeoff is fundamentally broken (Rule 1), nor a claim that the architecture fails globally from one candidate (Rule 2) -- it is a corrected, fair screening pass across all four candidates the discovery stage produced, using a metric protocol (fixed delay, signed derivative, frozen readout, candidate-specific diagnostics) that eliminates every specific defect named in the audit that started this pass. **Recommendation**: stop the confirmation campaign for this exact architecture and pursue the Krylov-sectorized memory design (not implemented here, per Rule 3).
