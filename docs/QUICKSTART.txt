⚠️ KNOWN LIMITATIONS & HONEST SCOPE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  • Quantum memory alone (qmem) sits at NRMSE ≈ 1 on k-Pauli.
    → Reason: reservoir features decay toward fixed point.
    → Workaround: use hybrid ID-QND-RC (quantum memory + classical delay).

  • CZ**t costs one gate on Willow, two gates on IBM.
    → Reason: IBM natively supports CZ (not parameterized CZ).
    → Mitigation: use qc.cp(t) which is natively parameterized.

  • Heavy-hex lattice (degree ≤3) is more constrained than Willow's square (degree 4).
    → Reason: fewer free neighbors for ancilla placement.
    → Mitigation: layout search adapts by choosing tap indices.

  • End-to-end device features have ~50% per-feature correlation with exact.
    → Reason: 8192-shot noise on classical shadows (Pauli variance ~1/√shots).
    → Compensation: MLP training absorbs noise; overall task accuracy unaffected.

  All of these are honest hardware limitations, not bugs. The sewing technique, 
  QND decoupling, and instantaneous depth all work as advertised on real noise.
