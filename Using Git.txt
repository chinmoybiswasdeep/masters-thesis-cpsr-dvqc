## Use case: Created a repo in GitHub, bring it to local, make some changes then reupload
git clone "https://github.com/your_repo.git"
git branch
git switch branch_name
git status
git add .
git commit -m "Message"
git push origin branch_name
->> From now on manage everything about the GitHub repo from your cloned repo

## Testing something on another branch
git checkout -b new_branch
git checkout source_branch file.ext
git push -u origin new_branch

## Downloading a file in a directory then pushing it online
->> make sure you have selected the branch
then add and commit to the branch, this will automatically remove from other branched, then push
